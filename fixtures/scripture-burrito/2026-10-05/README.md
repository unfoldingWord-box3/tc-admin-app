The 1 October recording (`../2026-10-01/`) holds seven of them and is kept for E37.

`worker/test/model/burrito.test.ts` loads every file here except `scripture_flavor_type.schema.json`, which references three files the upstream repository does not have (`book_scope`, `scripture/print_publication`, `scripture/braille_scripture_publication`) and which `source_metadata` does not reach. Notes for anyone validating against these files: `$$target` is a documentation keyword the schema tooling must ignore; `identification.schema.json` places `revision` and `timestamp` beside `required` rather than under `properties`, so their presence is checked and their values are not; `meta.dateCreated` is `format: date-time`.
