# Scripture Burrito schema, 1 October 2026

The schema files tC Admin's generated `metadata.json` must satisfy, copied from `https://raw.githubusercontent.com/bible-technology/scripture-burrito/master/schema/` on 1 October 2026: `metadata`, `source_metadata`, `identification`, `type`, `copyright`, `ingredients`, `ingredient`. The required fields they state are E37 in `docs/evidence.md`. The copy published at `https://www.burrito.bible/schema/metadata.schema.json` the same day was a stub holding only `meta` and is not recorded.
